== Description ==

This plugin displays a category tree and latest posts in the sidebar for category pages and single post pages.

Current features:

* Category tree based on the current context (category page or single post category)
* Parent display modes:
	* Show all parents
	* Show parent
	* Do not show parent
* Latest posts list modes:
	* Latest articles on selected category
	* Latest articles general
* Current category is highlighted in the tree
* Current post is highlighted in latest posts when viewing a single post

= Docs & Support =

You can find more detailed information about plugin on [GitHub](https://github.com/gruz0/widget-to-display-posts-from-current-category).

== Installation ==

1. Download the plugin from wordpress.org
2. Upload it to your site (if you've installed it through WordPress Admin Dashboard skip this step)
3. Activate the plugin through "Plugins" menu in WordPress
4. Go to "Appearance" -> "Widgets" and add the widget "Current Post' s Categories"
5. Configure widget options:
	* Category page widget title
	* Categories widget title
	* Single post widget title
	* Number of latest posts
	* Parent Categories Display
	* Latest Articles Scope
6. Save and enjoy
